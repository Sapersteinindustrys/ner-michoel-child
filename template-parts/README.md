Reusable partials pulled in via `get_template_part()` (e.g. a hero block,
a card grid, a staff/faculty listing) go here as they're built out.

For full page templates (`front-page.php`, `page.php`, `single.php`,
`page-*.php` for a specific page slug, etc.), add them directly in the
theme root — WordPress' template hierarchy picks them up automatically
by filename, no registration needed.
